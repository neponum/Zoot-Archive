# Правовой контур проекта (LEGAL)

Документ описывает, как в ZOOT Archive устроены страницы о правах, приватности и
обращениях правообладателей, и какие ограничения на контент из этого следуют.
Читать перед любыми изменениями, затрагивающими музыку, арт, аудио или сбор данных.

## Зачем это нужно

Проект — некоммерческий фан-архив. Права на Arknights, персонажей, сюжет, графику,
музыку и озвучку принадлежат Hypergryph Co., Ltd. и Yostar. Мы не претендуем на
оригинальные материалы и обязаны:
- не превращать сайт в коммерческий сервис (это ещё и требование Vercel Hobby);
- не хранить и не раздавать файлы правообладателя;
- убирать материалы по первому обоснованному обращению.

## Страницы

| Маршрут | Компонент | Содержание |
| :-- | :-- | :-- |
| `/disclaimer` | `LegalPage doc="disclaimer"` | статус проекта, права, чего мы не делаем, донаты |
| `/privacy` | `LegalPage doc="privacy"` | localStorage/IndexedDB, cookie, Discord, голоса, аналитика, права субъекта |
| `/takedown` | `LegalPage doc="takedown"` | порядок обращения, сроки, что удаляем сразу |
| `/legal` | redirect | ведёт на `/disclaimer` |

Все три документа рендерит `src/components/LegalPage.tsx`. Контакты, дата и ссылки
лежат в одном месте — `src/config/legal.ts` (`LEGAL_CONFIG`). Не хардкодить адрес
в компонентах.

Ссылки на документы: блок дисклеймера в `MainMenu.tsx` (главный экран) и футер
каждой правовой страницы. Заголовки вкладок — `usePageMeta.ts`. Sitemap —
`public/sitemap.xml`.

## Жёсткие ограничения по контенту

1. **Музыка.** `src/services/sirenCatalog.ts` умеет только читать каталог и метаданные.
   Скачивание треков и сборка альбомов в ZIP удалены вместе с `downloadAudio`,
   `saveBlob`, `extensionForContentType`, `estimateAlbumBytes`, `fetchAlbumTracks`.
   Воспроизведение — поток с официального CDN; кнопки ведут на
   `monster-siren.hypergryph.com/music/<cid>` (`officialSongUrl`).
   Не возвращать скачивание: это распространение чужого аудио.
2. **Голоса и сюжетное аудио.** Хотлинк на `torappu.prts.wiki` допустим только как
   воспроизведение. Кэширование «навсегда» и кнопки «скачать» — нет.
3. **Арт.** Официальные иллюстрации используются как оформление фан-архива. Полные
   галереи и сканы артбуков не размещать.
4. **Датамайн.** Непубличные материалы игры не публиковать.

## Данные пользователей

- Прогресс, плейлисты, настройки, черновики переводов — только в браузере
  (localStorage / IndexedDB), на сервер не уходят.
- Discord OAuth: хранится ID, имя, аватар, членство в гильдии; нужен для голосований
  и отчётов об ошибках.
- Голоса — `discord_<id>` + id эпизода в Vercel KV (`server/services/voteStorage.ts`).
- Аналитика — Vercel Analytics / Speed Insights, обезличенная, без tracking-cookie.

Любое новое поле с персональными данными требует обновления `/privacy` **в том же
коммите**.

## Коммерция

Vercel Hobby разрешает только некоммерческое личное использование. Пожертвования
прямо разрешены; реклама, платный доступ и партнёрские ссылки — нет. При появлении
любой монетизации проект обязан переехать на платный тариф или другую площадку.

## Чек-лист при изменении контента

1. Ничего не скачивается и не хранится на нашей стороне.
2. Новый источник данных указан в `docs/DATA_PIPELINE.md` и в allowlist прокси.
3. Если появились новые персональные данные — обновить `/privacy`.
4. Если менялся контакт — только `src/config/legal.ts`.
5. `npm run validate:data`, `npm run lint`, `npm run build`.
