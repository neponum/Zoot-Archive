# Чек-лист беты 0.1.0 (Android)

Проект выпускается как сайт и Android-приложение. Коротко: что проверить и в
каком порядке выложить. Сборка — `docs/BUILD.md`.

## 1. Перед тегом

- [ ] `npm run validate:data` — без ошибок.
- [ ] `npm run lint` — 0 ошибок TypeScript.
- [ ] `npm run build` — сайт собирается (Vercel).
- [ ] `npm run build:native` — сборка без PWA.
- [ ] Версия совпадает: `package.json` и `android/app/build.gradle`
      (`versionName`/`versionCode`).

## 2. Артефакт

- [ ] `npm run android:apk` → debug APK.
- [ ] `npm run release:collect` → `release/` + `SHA256SUMS.txt`.

## 3. Ручная проверка

Сайт:

- [ ] Терминал, история, эпизод, назад/домой.
- [ ] Читалка: глава грузится, ошибки показывают файл и причину, «Повторить».
- [ ] `/storage`: языки, прогресс, размер кэша, очистка.
- [ ] PWA ставится, обновляется без баннера.
- [ ] `/api/proxy` работает (художественные ассеты PRTS).

Android:

- [ ] APK ставится на чистое устройство.
- [ ] Back: модалка → история → выход, а не вылет наружу.
- [ ] Поворот экрана не сбрасывает главу.
- [ ] Статус-бар тёмный, контент не уезжает под вырез.
- [ ] Фоновая докачка текста стартует сама, прогресс виден в `/storage`.
- [ ] После перезапуска скачанный текст не качается заново.
- [ ] Hero-видео проигрывается; если нет — буквы MONSTER видны.

## 4. Релиз

- [ ] `git tag v0.1.0 && git push origin v0.1.0`.
- [ ] Дождаться `release-android`.
- [ ] В черновике релиза: описание изменений, требования (Android 8+),
      `SHA256SUMS.txt` вложением.
- [ ] Снять prerelease, только если все пункты выше закрыты.

## 5. Чего в 0.1.0 нет

- Автообновление APK: проверка версии по GitHub Releases — следующий шаг.
- Release-keystore Android: пока debug-подпись.
- Голос и арт офлайн-паками: качаются по требованию, как при чтении.
- Десктопные сборки отменены (решение 2026-11-15).
