# ZOOT Archive

[🇷🇺 Русский](#русский) | [🇬🇧 English](#english)

---

## 🇷🇺 Русский

**ZOOT Archive** — это профессиональный веб-инструмент, созданный для фанатов и переводчиков Arknights. Он позволяет легко парсить, переводить и читать сюжетные скрипты игры. Проект включает в себя удобный визуальный интерфейс, поддержку пользовательских переводов, интеграцию с Discord и ИИ-перевод на базе Google Gemini.

### ✨ Особенности
- **Продвинутый парсинг скриптов:** Автоматическое распознавание диалогов, имен персонажей, фонов и системных команд из сырых файлов сюжета Arknights (`.txt`).
- **Чтение сюжета:** Удобный интерфейс в стиле визуальной новеллы для чтения основных глав, ивентов и историй оперативников.
- **Интеграция с Gemini AI:** Контекстно-зависимый перевод, учитывающий пол персонажей, их отношения и специфическую терминологию Arknights.
- **Интеграция с Discord:** Безопасная отправка переводов на Discord-сервер через Webhooks с OAuth2 аутентификацией для проверки участников сообщества.
- **Мультиязычность:** Поддержка официальных языков (CN, EN, JP, KR) и фанатских переводов (RU, DE, ES и др.).
- **Аудио и эффекты:** Воспроизведение оригинальной фоновой музыки (BGM) и звуковых эффектов (SFX) прямо в браузере.
- **Постоянное хранение:** Ваш прогресс автоматически сохраняется в локальном хранилище браузера.

### 🛠 Технологии
- **Frontend:** React 19, TypeScript, Vite
- **Backend:** Express.js (для OAuth2 и проксирования)
- **Стилизация:** Tailwind CSS
- **Анимации:** Framer Motion
- **ИИ:** Google Generative AI (Gemini)
- **Аудио:** Howler.js

## 🇬🇧 English

**ZOOT Archive** is a professional web-based tool designed for Arknights fans and translators to parse, translate, and manage story scripts with ease. Powered by Google Gemini AI for context-aware translations and integrated with Discord for community submissions.

### ✨ Features
- **Advanced Script Parsing**: Automatically detects dialogue, character names, backgrounds, and system commands from raw Arknights story files (`.txt`).
- **Story Reader**: A comfortable, visual novel-style interface for reading main story chapters, side stories, and operator records.
- **Gemini AI Integration**: Context-aware translation that understands character gender, relationships, and Arknights-specific terminology.
- **Discord Integration**: Securely submit translations to a Discord server via Webhooks, with OAuth2 authentication to verify community members.
- **Multi-Language Support**: Support for CN, EN, JP, KR, RU, and many more.
- **Audio & Effects**: Playback of original background music (BGM) and sound effects (SFX) directly in the browser.
- **Persistent Storage**: Your progress is automatically saved in your browser's local storage.

### 🛠 Tech Stack
- **Frontend**: React 19, Vite, TypeScript
- **Backend**: Express (for OAuth2 proxying)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **AI**: Google Generative AI (Gemini)
- **Audio**: Howler.js
